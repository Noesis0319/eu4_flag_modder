# EU4 모드 제작기

## 실행 파일(exe) 받기

`EU4ModMaker.exe` 같은 빌드 산출물은 이 레포에 커밋하지 않는다. 아래 둘 중 하나로 받는다

- **GitHub Releases**: 레포의 Releases 페이지에 올라온 exe 를 내려받는다
- **직접 빌드** (Windows): Python 3.10 이상을 설치하고 `build_exe.bat` 를 실행하면 `dist\EU4ModMaker.exe` 가 생긴다

소스에서 바로 실행하려면 `pip install -r requirements.txt` 를 하고 `run.bat` (또는 `python main.py`) 를 실행한다
